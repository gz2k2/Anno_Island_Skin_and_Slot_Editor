# Anno 1800 Island ReSkinner by gz2k2

# Changelog

## [v0.98.4] - 2026-10-25

### Added
- Added Mine Slot options to the "Slot Map".
- Object Map: Movement Mode allows all objects within a selected area to be moved.
- Tintmap Settings: Tintmaps can now be patched (e.g., Old World islands in Enbesa will appear darker and no longer shine as intensely).

### Changed
- Slots can now be rotated via the right-click context menu.

### Fixed
- UI and general code fixes.

### Known Issues
- RiverSlot and MineSlot directional arrows on the map may deviate; please verify orientation in-game.
- Please report any other bugs you find!
