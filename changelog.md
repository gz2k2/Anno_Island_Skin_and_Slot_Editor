# Anno 1800 Island Skin and Slot Editor by gz2k2

## [v0.107.24] - 2026-10-27

### Added
- **Custom Objects Tab**: Custom Objects can now be defined and used under "Objects Configuration" (e.g., for custom sessions like *White and Cold* or *New Horizon*, which utilize custom objects). Support for creating Custom Categories and Custom Regions has been added. Custom Regions, Categories, and Objects feature a `(c)` tag in their text to clearly distinguish them from default entries.
- **Custom Files Export**: Custom files can now be defined. If custom objects are used under "Object Configuration" and found in the "Custom Objects" folder, clicking the "Export custom content files" button will include them in the export.
- **Lasso Selection**: Added a "Lasso" selection tool to both the Slot Map and Object Map alongside the box selection (`CTRL + Left Mouse Button`).

### Changed
- **Create from Original Maps**: Added a new pop-up window interface. Maps can now be filtered by region, and a map image preview is displayed on the right side.
- **Settings Tab**: Cleaned up the Settings tab layout, now organized into categorized sections.
