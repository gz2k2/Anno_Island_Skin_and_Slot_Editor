# Changelog

## [v0.117.12]

### Changed
- **Rocks & Pebbles Mapping**: Rocks and Pebbles now map to their equivalent versions across other regions. Enbesa rocks (reddish) are an exception as a 1:1 mapping is not possible, so they map to/from a similar rock type instead. *(Special thanks to Hier0nimus for the help!)*

### Fixed
- **Slot Functionality**: Resolved an issue affecting slot operations.
- **Mine Slots**: Mine Slots now feature correct work area alignment, and Bezier paths are now calculated accurately (needs further opimization).
