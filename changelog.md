# Changelog

## [v0.120.13]

Updated NW to Enbesa Material Set

## [v0.120.12]

### Added
- Rivercolor can now be changed in Regional Settings.
- Tint Map settings can now be saved as presets.

### New
- The Anno 1800 Mod folder can now be configured in Settings.
- Tab Finalize: New Button: "Export Editor Mod Files"-  Exports Island Editor mod files, including material sets and integrated River Slot files.
- Custom Slot / River Slot GUIDs can be defined under Custom Content.
- Slot Map: Added 2 Drop Down Menus for River Slots and Custom Slots. 

### Fixed
- The Slot Editor could write some data to the wrong XML path, corrupting island data.
